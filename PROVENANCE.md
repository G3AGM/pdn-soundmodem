# Provenance

Status: reference as of 2026-10-05 (licence statement revised for the move to AGPL-3.0-or-later; the component rows are as of 2026-09-17). Describes what every part of this codebase is based on, and the licence that follows from it. Components that have since left the repository are named here with the package they went to; each of those packages keeps its own PROVENANCE.

Apart from the ka9q_ubersdr decoder port (`UberSdr/PcmBinaryDecoder`), nothing here is a line-by-line translation of another program, but several components are derivative, with formulas, constants and bit-level behaviours taken from GPL sources. Those files stay GPL while the repository as a whole is AGPL-3.0-or-later; [LICENSING.md](LICENSING.md) lists them and says why, and the last section below explains how the two fit together.

Much of what this file was written about now ships as a package rather than as a folder here. Every dependency in `Directory.Packages.props` whose name begins `M0LTE.` was lifted out of this tree, and each one records in its own repository the provenance of the code it took. The rows below keep the lineage regardless, because it was true when the code was written and moving it changed none of it; each row names the package and the path the code had here. `M0LTE.FmChannel`, the FM link model that came out of the test project, is the same story, and `tools/Packet.SoundModem.Ota` is what references it now.

## The four kinds of source

1. **Published specifications, read directly**: the [IL2P specification draft v0.6](https://tarpn.net/t/il2p/il2p-specification_draft_v0-6.pdf) (Nino Carrillo KK4HEJ) including its worked example packets (provided by Jon Naylor G4KLX); the AX.25 v2.2 specification (HDLC rules, CSMA); the KISS specification; the FX.25 draft (Stensat, 2006, via archive.org).
2. **Dire Wolf source, read directly during development** (GPL-2.0-or-later, © John Langner WB2OSZ): `il2p_scramble.c`, `il2p_header.c`, `il2p_init.c`, `fx25_init.c`, `fx25_send.c`, `fx25_rec.c`, `gen_tone.c`, `hdlc_rec.c`, `hdlc_send.c`, `demod_9600.c` (in part).
3. **QtSoundModem** (GPLv3+, © Andrei Kopanchuk UZ7HO, ported by John Wiseman G8BPQ), read in full by the research phase that founded this project (see packet.net `docs/research/headless-soundmodem.md`): its findings supplied algorithms, formulas and constants used here. No QtSoundModem C was transcribed.
4. **Empirical determination**: several wire-format facts were established by experiment, not by any document - encoding against the IL2P spec's example packets byte-for-byte, decoding Dire Wolf-generated audio and having Dire Wolf's `atest` decode ours (bidirectional cross-validation, fixtures committed in `tests/Packet.SoundModem.Tests/Fixtures/`), and benchmarking against the WA8LMF TNC Test CD. The CRC-16/X-25 variant, the legacy max-FEC header bit behaviour, the 9600 IL2P baseband polarity, and the NRZI/scramble ordering are all in this category.

## What was not taken

QtSoundModem's program structure (global state, threading, buffer handling), its Memory-ARQ and dual-threshold recovery machinery, and Dire Wolf's multi-slicer are not ported. Where this project needed equivalents it either engineered its own (envelope slicer, dedup, busy detector) or recorded the lever as future work in [docs/dev/plan.md](docs/dev/plan.md).

## Licence consequence

Components above carry material derived from Dire Wolf (GPL-2.0-or-later, upgradeable), UZ7HO/QtSoundModem (GPLv3+), MMDVM-TNC (GPL-2.0-or-later, upgradeable) and ka9q_ubersdr (GPL-3.0). At the project's founding the whole repository was made **GPL-3.0-or-later** (packet.net `docs/research/headless-soundmodem.md` §4 and §Decisions, 2026-07-14), the conservative choice for code written with both GPL trees having been read.

On 2026-10-05 Tom moved the repository to **AGPL-3.0-or-later**. That covers everything he and Claude wrote, and Tom Wardill's template-unit contribution (PR #477), which he agreed to relicense the same day. It cannot cover what was taken from those GPL programs, so the files carrying that material keep their GPL licence: GPL-3.0-or-later, except the ka9q_ubersdr port, which is GPL-3.0-only because its upstream does not say "or later". Each such file has an `SPDX-License-Identifier` header and a row in [LICENSING.md](LICENSING.md) giving its reason. The deciding test is the table above: a file that took code, formulas, constants, tables or bit-level behaviour from a GPL source stays GPL; a file that only follows an idea, or names a GPL program to compare with it or interoperate with it, is AGPL. LICENSING.md also lists the borderline files that were considered and left AGPL.

GPLv3 §13 and AGPLv3 §13 each permit linking or combining a GPLv3 work with an AGPLv3 work and conveying the result. Each part keeps its own licence, and AGPL §13's network-source requirement applies to the combination, so the program as built is used on AGPL terms. That was already true before the change, because `M0LTE.Flex`, `Packet.Ax25` and the other AGPL dependencies brought AGPL §13 onto the combined work.

Moving a component into a package changed neither what it derives from nor what licence it carries. `M0LTE.Il2p` and `M0LTE.FmChannel` are GPL-3.0-or-later; `M0LTE.Ardop`, `M0LTE.Dsp`, `M0LTE.Fec`, `M0LTE.FecLdpc`, `M0LTE.Flex`, `M0LTE.Ofdm`, `M0LTE.Pocsag` and `M0LTE.Radio.Audio` are AGPL-3.0-or-later, as are `Packet.Ax25` and `Packet.Core` from 0.26.0. Nothing here may be copied into an MIT-licensed package, and no MIT-licensed package may depend on `pdn-soundmodem`.
